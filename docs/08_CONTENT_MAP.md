# CONTENT_MAP

未提供のコピー、画像、CTA、データ、フォーム項目、設定項目はプレースホルダーとして維持する。

## 7. Content Integrity Rule

- コンテンツを新規作成しない
- 提供されていない内容を補完しない
- 提供済みコンテンツを勝手にリライトしない
- 架空の本番収支データを作らない
- 未決定事項は対応するTBD placeholderのまま維持する
